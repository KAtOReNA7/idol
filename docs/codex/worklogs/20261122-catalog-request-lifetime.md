# 冷启动时打开作品的目录 502

v234 中，IVE《LOVE DIVE》和 XG《WOKE UP》都曾在点卡后收到 HTTP 502。同期 BADVILLAIN、ODD YOUTH、Kep1er 的团目录也各发生一次。五次错误来自原生目录的读表阶段，五个请求都在等待同一 Worker 中另一请求发起的异步读取。正式日志未保留异常原文。[正式调用记录](../evidence/20261122-v234/catalog-joined-read-errors.json)

隔离环境使用同一份合成 D1、真实 workerd 和两个版本各自的目录代码。让首个 HTTP 请求在数据库查询已经发出、读取尚未完成时结束，随后连续打开同一个作品两次。旧版复现了与正式所有者请求相同的步骤、错误类别、HTTP 状态及补读次数。workerd 在这个条件下会丢弃已结束请求的未决操作，等待它的后继请求拿不到结果。[隔离对照](../evidence/20261122-v235/catalog-request-lifetime.json)

| 隔离操作 | v234 | v235 |
|---|---|---|
| 结束首个请求后，所有者第一次打开作品 | 502 | 200，正确作品，可读个人评分 |
| 同条件下访客第一次打开作品 | 502 | 200，正确作品，只读公开数据 |
| 两种身份随后各再开一次 | 均需重新读表 | 均命中已完成的目录，额外读表 0 次 |

v235 仅在同一个 HTTP 请求内合并未完成的目录操作。作品点击、团页和访客查询之间可以复用已经完成、已核准所有者、快照和数据版本的目录。每次仍按请求的身份读取个人评分并检查数据版本。独立回归还覆盖前一个请求失败、并发保存、切换数据来源和所有者变化。四个目录与详情专项共 56/56 项通过。[读取器](../../../apps/idol-site/lib/idol/native-reader.ts) · [并发回归](../../../apps/idol-site/tests/native-catalog-cache.test.cjs) · [workerd 与 D1 回归](../../../apps/idol-site/tests/work-detail-d1.test.cjs)
