# BABYMONSTER 的首次搜索与清空

正式 v255 的《BILLIONAIRE》分享页在第一份 HTML 中已显示正确作品和「清空」，但该按钮需要等待前端接管。桌面正式实测中，首次点击没有清空。匿名 HTTP 核对也发现页面没有可提交的搜索表单。

作品目录现在提供原生 GET 搜索和「清空」链接。按 Enter 或「搜索」均可提交。前端接管后仍随输入即时筛选，普通清空点击会把焦点交还输入框。本人选择的观看队列会随搜索和清空保留，只有「查看全部作品」同时清除队列和关键词。

| 相同入口与操作 | 正式 v255 首份 HTML | 本机 5173 首份 HTML |
| --- | --- | --- |
| 打开 `?section=works&q=BILLIONAIRE` | 1 支作品，无清空链接 | 1 支作品，沿「清空」链接返回 19 支作品 |
| 从同页提交 DRIP | 无 GET 表单 | 1 支《DRIP》，其 MV 返回地址保留 DRIP 搜索 |
| 清空 `?section=works&queue=rewatch&q=DRIP` | 依赖前端按钮 | 清空后保留 `queue=rewatch`，访客没有私人记录 |

本机结果取自正常页面的 HTTP 200 响应。分享目录专项 10/10 通过，其中两项新增测试覆盖无脚本表单、清空链接与队列，以及接管后实时输入、提交、焦点和组合键点击。五组目录与导航测试共 71 项，70 项通过，唯一失败是 v255 已记录的七人图片旧断言。[v255 同项记录](../evidence/20261123-v255/full-suite-failures.csv) 正式复验随下一批发布。
