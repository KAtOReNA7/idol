# NewJeans 和 SAY MY NAME 的字体请求

正式 v239 的 NewJeans 首页在 375 px 正文加载了 `NewJeans Nunito Sans`，SAY MY NAME 首页在 1425 px 加载了 `SmnBody`。两个页面实际请求同一份 571,240 字节的 Nunito Sans。网页正文和已加载字体均从 Codex 内置浏览器读回。正式域名接受压缩编码的匿名请求也实收 571,240 字节。[双页正式基线](../evidence/20261122-v239/home-font-baseline.json)

新的完整 WOFF2 文件为 208,864 字节，同一文件首次请求减少 362,376 字节（63.44%）。沿用项目的字体转换器，逐项核对 1,104 个字形、939 个字符映射、提示和排版表。字重、字宽、字号和小写字高四个可变轴完整。登记该字体的两个团页、NewJeans 团体卡及作品主题统一优先使用 WOFF2，原家族、字重范围、字宽和回退均继续生效。[字体转换和完整性检查](../../../apps/idol-site/scripts/build-editorial-fonts-woff2.py)

另有四处 Instrument Serif Italic 声明现在优先使用项目已有 WOFF2。该字体两种格式的 377 个字形轮廓与宽度、333 个字符映射及排版完全一致。正式域名两种格式均返回 200，单次取用的大小从 71,592 降到 28,096 字节。这四处含早期的 ILLIT 页面和已更换布局的标题，实际访问只有命中该字体才会减少请求字节。

Windows 和 WSL 分别通过 45 项字体、页面主题、缩略图和构建保护用例，51 团主题的样式重新生成后核对一致。字体字节比较采用同一字体的两个完整格式，整页加载时间及新格式上线后的实际请求另行测量。
