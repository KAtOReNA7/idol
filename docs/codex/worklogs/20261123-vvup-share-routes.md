# VVUP 分享链接的首份网页

成员、舞台和时间轴的分享链接原先都会先显示「正在打开 VVUP 档案」，页顶还会出现首页团照。现在直接打开这三个地址，首份网页就会显示对应栏目。沿用了 VVUP 已验收的团页版式。成员卡和舞台卡都是实际链接，键盘和指针均可访问。[v246 正式基线](../evidence/20261122-v246/v246-six-shared-links.json) · [原版桌面与手机设计](20261024-vvup-review-completion.md)

| 分享地址 | 原首份网页 | 新首份网页 |
| --- | --- | --- |
| `?section=members` | 0 张成员卡 | Kim、Paan、Suyeon、Jiyoon 四人均可打开。选择历史名册可查 Hyunny |
| `?section=works&format=stage` | 0 张舞台卡 | 六场节目各有封面、作品名、节目来源、日期与站内链接，「可看舞台」已选中 |

Windows 上用相同路由参数分别模拟首份响应和实际目录返回。三个目标标题从 0/3 到 3/3，三栏条目数、身份及顺序均与目录加载后相同。六张首屏舞台卡逐项核了封面、日期和目标地址。待看、高分等个人筛选等实际记录读回再展示，已有的 0 分可正常显示。资料库和时间轴读取失败各自保留重试入口。[三条地址同条件对照](../evidence/20261123-v250/vvup-shared-first-html.json)

TypeScript 检查通过，分享页与目录等五个文件 26/26，VVUP 图片宿主和时间轴 7/7，独立审阅路由与隔离读取 13/13。上述结果来自本机组件与路由测试，正式浏览器复验随本版发布记录交付。
