# 访客使用中的四个待决定问题

2026-11-22。按找作品、观看和读档案的实际操作整理。48 个 React 团页共 144 个路由已逐团核对。91 个同时展示 MV 和发行的页面均先出现 MV。以下讨论区分正式站实播、候选页面渲染和访客测试建议，目前没有真人任务耗时或误点率数据。[逐团排序记录](worklogs/20261122-artist-media-order.md) · [跨团浏览与返回记录](worklogs/20261122-group-journeys.md)

| 访客会遇到什么 | 建议讨论的范围与取舍 |
| --- | --- |
| **点进同名影像，会看到哪个版本？** W!TCHX 的《BLALA》同时收录官方歌词版和 Moving Mix 4K。ADYA 的《A Dazzling Day》是 OST MV。对照正式目录，48 团中有 42 个原需跳转或绕行的首页入口能按同团、同视频 ID 直达本站作品，另有 6 团共 10 个版本缺少唯一匹配，仍进入原版本详情。 | 可先对这 10 张卡试用「查看歌词版」「查看 OST MV」等已有来源支持的动作标签。这样在点击前就知道版本，也能保留原视频；手机卡片会多占一行。新增站内作品及评分关联需要逐项取得对应版本证据。[52 张卡及逐项结果](evidence/20261122-v211/react-featured-mv-targets.json) |
| **首选线路能否提供足够清楚的画面？** ILLIT《Magnetic》的官方 B 站嵌入页曾静音实播到 24.57 秒，解码为 640 × 360；同曲的另一条线路实测为 1920 × 1080。BABYMONSTER《BILLIONAIRE》的 B 站来源为转载，正式站样本解码为 640 × 294。 | **B 站低清播放已明确禁止。** 上述两次低清结果应从可播放线路中排除。待讨论的是是否在合格线路旁显示发布者身份、平台和实测清晰度，以及怎样让访客看懂当前线路。注明最近一次实测可帮助选择，也须保留网络条件与测量时间，避免把旧读数当作本次播放保证。[两条 B 站来源和实播进度](evidence/20261122-v211/playback-sources.json) · [另一线路的高清实测](worklogs/20261122-work-player-retries-v210.md) |
| **看团体成绩时，这个 0 可以拿来比较吗？** SPIA、TRACER、VCHA 和 W!TCHX 的累计销量暂无可采用的总数，按已采纳规则显示 0。XG 的音乐节目一位来源记录为 0 次，来源未注明截止日。UDTT 的 103 张则是《School Rush》和《VIPER》两个单日记录之和。 | 待决定的是说明放在哪里。可在这六团的摘要数字旁试放「暂无累计数据」「来源记录 0 次」「两日合计」，完整日期和出处仍在详情。摘要会稍长，跨团阅读时能更早看见统计范围。评分中的 0 继续是有效输入。[访客文案核查](worklogs/20261122-public-facing-copy.md) · [统计口径与已采纳展示规则](research-closeout-20261101.md) |
| **手机上点「作品」，能找到哪些内容？** UNIS 的同一入口桌面写「发行与影像」，手机缩为「作品」。VVUP 的「影像」和「发行」分别进入两个目录。ODDYOUTH 的作品分类写「发行」，实际对应的全部视图同时列出发行和影像。 | 建议在这三团的手机与桌面上各做一次「找到一张发行，再打开一支 MV」的任务，记录入口选择与是否回退。可只调整容易误判内容范围的文字，保留各自版式和已熟悉的短标签。若统一所有团的名称，仍需区分仅有影像和同时收录发行的两类目录。[UNIS 宽窄屏标签](../../apps/idol-site/components/design-review/unis-design-review.tsx) · [VVUP 栏目](../../apps/idol-site/components/vvup-artist.tsx) · [ODDYOUTH 分类](../../apps/idol-site/components/oddyouth-artist.tsx) |
