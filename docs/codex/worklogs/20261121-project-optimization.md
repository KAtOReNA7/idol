## 工程实施

正式工程已有一套跨平台验证命令、分层 CI 和可重建的本地合成 D1。主站将作品详情、成员详情、原图展示及编辑器拆分，按访问需要载入。图片授权索引按 owner、快照、模式、epoch、generation 隔离。集中核对目标使用现有复合主键，完整保存日志仍在同一个 D1 batch 内读取。[首页入口](../../../apps/idol-site/app/page.tsx) · [公开图片读取](../../../apps/idol-site/lib/idol/public-reader.ts) · [评分核对](../../../apps/idol-site/lib/idol/stage-owner-preflight.ts)

第二轮对照 Figma 和真实截图时，发现主站主题的两列规则占用了手机筛选区的第二列，导致「更多筛选」与分类按钮挤在一起。实现改为单列，四个分类各有独立触控区域。浏览回归增加 320 像素宽度以及每个按钮的尺寸、边界和间距断言。

依赖审计剩余的两条根公告分别来自 satori 的 fflate 和 Drizzle 工具链的 esbuild。两个子依赖单独升级，保留原构建框架和迁移工具的版本。最终复扫使用更新后的锁文件，运行验证使用由该锁文件重新安装的实际模块。

逐团复核时，IVE 的目录读取缺少其他团页已有的 JSON 类型和评分数组校验。14 团现在共用一个只读目录请求，保留各页的取消、路由、设计与重试状态。12 个单独页面与 XG、aespa 的共享页面已加进当前回归。图片选择夹具改用按文件与调用方匹配的合成元数据，导航测试为八份公开键表补上内容指纹、来源和字段检查。增加可复跑的 51 团两宽浏览入口，以及三宽搜索、翻页及展开截图。

归档迁移夹具原先按 Unix 文件分隔符识别读取模块，Windows 误走了另一套读取接口。改为比较文件名后，18 项合成迁移测试通过。旧页面内联 URL 断言已迁到共享读取函数及各页的实际调用。仓库另附两个本地预览之间的交错测量脚本，输出完整样本、中位数及公开目录摘要。

导入器在普通 Python 及 `-O` 下都执行来源与评分保护。普通官方 YouTube 的新增同样需要真实 owner 核对空分、没有目标保存日志以及线上前像，0 分按已有评分处理。研究状态变动会保留已经采用、等待发布的来源。写入前记录三个文件的前像，互斥写入，在中断后恢复。三处替换点的进程中断、竞争写入、重复执行、外部文件变化、前像不符和有保存日志均以合成数据验收。[批次写入](../../../apps/idol-site/scripts/stage_batch_files.py) · [输入校验](../../../apps/idol-site/scripts/merge-stage-batch.py)

两个传递依赖的实际安装版本为 `fflate 0.7.5` 和 `esbuild 0.25.12`。TypeScript 转译及 Drizzle 迁移检查通过。项目本地字体生成 160×80 PNG 的烟测通过，直接从工程根目录调用独立 `@vercel/og` 时，上游 Node 入口查找当前目录的 `hb.wasm` 会失败。从随包安装的 HarfBuzz 资源目录启动可生成 PNG。本站当前页面与 API 没有直接使用该入口。
