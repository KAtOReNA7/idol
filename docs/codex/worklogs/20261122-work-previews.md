同一份公开目录分别驱动 v207 提交 `150f5c0b` 和候选组件。按各团的实际卡片节点统计，固定展示的编辑栏目可能在多个筛选页重复。ifeye 的默认作品页只展示发行，切换影像和舞台后分别核了 4 张及 3 张卡。全站另有九个尚未选曲的原始占位。[逐团 154 个页面状态与选择器](../evidence/20261122-work-previews/artist-directories.csv) · [输入、统计口径与结果](../evidence/20261122-work-previews/review.json)

MEOVV 的 19 张视频卡从 11 张有图补到 19 张。i-dle 保留团页设计图，公开影像和手帐目录合计从 15/36 补到 36/36。Billlie 的日版《DOMINO》练习室、GENBLUE、BEWAVE、YOUNG POSSE、WOOAH 及 ifeye、izna 的独立舞台目录也已接上对应视频封面。[逐团实测](../evidence/20261122-work-previews/artist-directories.csv)

527 个舞台播放器保留 51 张既有专项图，474 个采用上传方提供的该视频缩略图。IVE 与 NewJeans 的两段 Lollapalooza 演出使用关联作品图，界面明示「关联作品 MV 封面」。STAYC 日版《Teddy Bear》沿用核准分 P、时间区间的专项画面。四个 B 站舞台和一个 X 舞台也逐项核了来源身份。[527 项的前后图片及媒体身份](../evidence/20261122-work-previews/stage-details.csv)

按精确视频 ID 取回 476 张候选，部署使用其中 431 张，共 11,071,674 字节。另 45 张已有对应专项图或既有图片满足调用。424 张采用上传方大图，7 张采用较小的上传方图，去除已核对的对称黑边后保留 480 × 270。新 WebP 最多宽 640 像素。发布素材清单记录了来源 URL、原图及成品 SHA-256、裁切坐标与尺寸。[逐图交付清单](../evidence/20261122-work-previews/stage-assets.csv)

Windows 上核对了 1,395 个实际引用的公开图片路径，1,366 个位图全部解码，29 个 SVG 全部解析。使用 Node 和 React 渲染真实目录、全站作品卡和详情播放器，ifeye、izna、UDTT 另走各自的原生渲染器。该项检查没有浏览器视口，页面视觉与线上回读使用发布记录中的独立测量。[验证范围](../evidence/20261122-work-previews/review.json)

三个图片与时间轴矩阵共 317 项通过。九个相关测试文件共 95 项，74 项通过，余下 21 项在 v207 的同名用例也失败。针对 Hearts2Hearts 同名版本新增了一项实际团页回归，已通过。节目替代、公开资料与版本展示的六个兼容性测试文件共 68 项通过，TypeScript 检查通过。[测试口径](../evidence/20261122-work-previews/review.json)
