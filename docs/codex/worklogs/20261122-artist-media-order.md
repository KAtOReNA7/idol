## Billlie 首屏的实际显示顺序

主会话用 Codex 内置浏览器逐团检查正式 v211 的 51 个首页。实际正文宽 1265 px 时，只有 Billlie 的发行封面高于 MV。MV 入口顶边在 410 px，发行封面顶边在 186 px。原两栏网格把 MV 放在左栏大字标下方，右栏的发行封面从网格顶端开始。

首页现将字标和 MV 放在跨越全部栏的第一行。桌面第二行展示发行说明和原方形封面，手机依次显示 MV、发行说明和封面。以实际团页渲染核对了 MV 的站内作品链接、发行标题和原封面 URL，并检查了 320、375、390、767、768、1265、1440、2048 px 的网格规则。Billlie 宽度与 48 团排序专项合计 55 项通过，TypeScript 和 Git 差异格式检查通过。补丁的浏览器几何读数由主会话在发布复测中记录。
