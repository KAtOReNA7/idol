# Public member-career projection

`periods.json` is generated by `python scripts/build-member-career-display.py` from the reviewed canonical research. It contains all 368 accepted periods, stable period/source IDs, semantic dates and a canonical content hash. It excludes the held period, member-field proposals, all 24 blocked overlays, audit summaries, private catalog fields and raw source evidence.

The UI and native/live JSON exports import the same versioned object. The display omits 62 roster observations, requires a matching real member ID and current/former group relationship, and renders event dates rather than invented membership ranges. Missing endpoints never mean “present”. Public debut, lineup announcement, self-introduction, report publication, member activity end and whole-group activity announcements retain separate meanings. Explicit editorial event mappings in the generator cover facts without membership dates; they never fill the original date fields.

`MemberCareerFacts` preserves the current database profile and official URL. It does not apply profile overlays, modify role/relations, or write any personal records. All user edits remain database-owned. Empty content renders no placeholder section. Browser imports do not reach the research directory.
