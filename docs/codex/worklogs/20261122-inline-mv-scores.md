# MV 成员照片下的评分

本人在《BILLIONAIRE》的《DRIP》发行阵容区，可以直接在七位成员各自的照片下填写表现分、造型分并保存。同一成员另有原生评分关系时，两张照片的入口使用同一个原生编辑器，切换位置保留未保存的值。按团体名册手动选择其他成员后，页面在该成员的档案参考照下打开评分。公开署名和照片沿用各自的出处与适用范围。[本人评分及鉴权规则](20261122-personal-mv-ratings.md)

## 逐卡覆盖

在 51 团 614 条作品中，599 支可评分 MV 共涉及 4,195 个作品与成员组合。3,466 个入口直接显示在照片卡上，另 729 个按名册选取后显示。逐项渲染的卡片均含图片地址和相应评分入口。六支已确认无成员真人出镜的 MV 保留整体评分，另有九条占位。ILLIT 韩语合作版的 JISOO、MOMOKA 按该作准确的视频及具名署名进入对应成员卡。[逐团统计、适用数据和方法](../evidence/20261122-inline-mv-scores/coverage.json)

照片检查读取本地服务端渲染的图片地址。具名参考照、本人已有作品照片、成员档案照片继续保留相应说明。未在这一轮逐张联网解码。各团作品数按该团被列入作品统计，因此跨团作品在总数中按作品去重。[逐项数据口径](../evidence/20261122-inline-mv-scores/coverage.json)

## 内置浏览器

在宽 1280 CSS 像素的本机隔离页面中，RUKA 的同一照片卡重复打开后只有一个表单。填入表现 0、造型 8.5，切到舞台再返回后保存，刷新仍在该卡读到 0 和 8.5。另用一条合成原生关系在两个照片来源间移动编辑器，保留同一组未保存值和脏状态，两个位置共一个表单。访客页面显示七张具名照片，编辑入口与私分摘要均为零。浏览器操作仅使用内存中的合成评分。[浏览器回读](../evidence/20261122-inline-mv-scores/in-app.json)
