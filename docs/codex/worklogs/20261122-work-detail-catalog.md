# 直达一支 MV 时按作品读取

从团页或分享链接直接打开一支 MV，以前会先下载整个作品库。详情现在使用作品 ID 请求当支作品、原舞台与评分绑定、同版跳转目标、成员、历史成员、具名合作与对应评分记录。单个窗口已经打开全馆时继续复用其目录。恢复有「下一首」的观看队列会读取全馆，跳转到搜索或全馆导航也会先取得完整数据，再显示计数和列表。

同一份匿名项目快照、同一 HTTP 入口下，51 团的 614 个直达入口逐一核对通过，含 605 个有影像的作品和 9 个占位页。每次完整读取为 1,955,086 个解码字节，改后单支中位数为 6,877.5 字节，范围为 3,258–23,519 字节。若每首各独立直达一次，合计从 1,200,422,804 降至 4,514,566 字节，下降 99.62%。从已经打开的作品库点下一首本来就能复用数据，按原方式计。[逐团结果与使用条件](../evidence/20261122-v215/work-detail-catalog.json)

| 团页首支作品 | 目录解码字节 | 保留成员 | 本支评分关系 |
|---|---:|---:|---:|
| IVE | 1,955,086 → 7,969 | 6 | 6 |
| ADYA | 1,955,086 → 5,923 | 5 | 5 |
| Cherry Bullet | 1,955,086 → 8,480 | 10 | 7 |

按 `Prefer: omit-stage-candidates, work-detail=<作品 ID>` 协商。ID 必须在当前可读目录中唯一且格式有效，删除、重复或过长的 ID 会按原全馆契约返回。旧服务返回的完整目录同样可以直接使用。团页既有的目录范围优先；原始读取、导出及私人写入沿用原入口。已有评分索引可按 owner、当前快照、作品三个条件取个人 MV 分，保留账号、视频身份、成员、版本号与历史记录校验。

隔离 D1 通过真实目录接口复测了 The Chase、RING X RING、TOMBOY 和 Attention 的写后读。断线重试后，每支作品的 0 分、舞台 9.1 分、成员 0 分与原备注均能读回。并行编辑的合成测试覆盖旧修订冲突、确认新修订后清空以及另一支作品的分数保留。原生版本资料另外检查 71 个已核身份、36 对关联的 72 个有方向的跳转。三团直达、作品库、返回和保存共用原导航入口。

公开大小取自本地 HTTP。该本地地址未获自带浏览器访问权限，首卡至播放器按钮可见的时间需由正式站的同条件浏览器对照记录。项目的匿名测试服务运行时可用下列命令复测全部响应。

```sh
node tests/browser/work-detail-catalog.cjs http://127.0.0.1:8873
```
