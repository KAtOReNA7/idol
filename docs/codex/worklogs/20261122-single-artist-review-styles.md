# 逐团静态审阅包的作品与目录样式

28 个审阅入口共用正式作品页和团体索引。两张共享样式表原来会带入所有团体的字体，即使页面只显示一个团。以 VVUP 为例，构建遇到 Rocket Punch 的 Open Sans 后中止；GENBLUE 和 WOOAH 遇到 ADYA 的 Archivo Narrow 后中止。

构建现在只提取本团的作品主题和索引所用的字体，一并保留该字体的字重和语言分片。作品、音乐导航和通用候选页沿用正式页面的三张公共布局样式。原有各团素材目录、原件绑定、只读 API 和禁止私人数据进入浏览器的检查继续执行。

| 同条件检查 | 修前 | 修后 |
|---|---:|---:|
| 逐一执行 28 个独立构建 | 1 个完成 | Windows、WSL 各 19 个完成 |
| 因混入其他团的字体而失败 | 18 个 | 两端均为 0 个 |
| izna 静态包的作品与首页 CSS | 213,736 字节 | 127,824 字节，减少 40.2% |
| izna 实际打包的字体文件 | 64 个 | 1 个 |

基线使用冻结提交 `b5b514ca` 的 28 个原构建脚本，读取当前工程的同一批数据，使用默认原件投递模式。修后 19 个包逐一检查了真实输出目录、清单、CSS 引用、字体文件和保留的主题。每包只含本团的作品主题，跨团 `/artist` 字体为零。独立样式回归覆盖全部 28 个入口，包括打包前就被舞台来源校验拦下的 9 个。[逐团构建及未通过的具体作品](../evidence/20261122-single-artist-review-styles/builds.json)

ifeye 的目录图片已与审定原件共用同一张 JPG，验收改查完整图片集合。KiiiKiii 的作品样式由正式导航按需加载，验收同时检查公共首屏样式、实际加载地址及该文件与正式源文件的字节。历史路由文件及新增样式回归共 171 项，Windows 与 WSL 各通过 168 项。余下 Hearts2Hearts、SAY MY NAME 和 YOUNG POSSE 的 3 条测试均因历史视频身份差异失败；同批路由文件在 v236 的 17 条失败中有 14 条已恢复。

9 个仍被拦下的完整包中，7 个首处差异是旧清单中原本留空的主舞台后来有了已绑定来源。KATSEYE《Gnarly》的原舞台已进入替换历史，YOUNG POSSE《나의 이름은 (ROTY)》的一条旧后备源已被移除。这些作品需按已审核的公开版次对齐后，再重新验证整包。此项交付覆盖静态审阅工具和测试，访客正式站的体验另按发布批次验收。
