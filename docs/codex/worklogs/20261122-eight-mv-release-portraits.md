## 余下的发行期照片

NewJeans《Attention》处理后的 194 个明确跨期位置落在 15 团、34 支 MV。本批 48 个完成选图。其余 146 个位置逐人列出作品、视频、成员、原卡、发行、具体来源和下一步。124 个已找到当次发行图集，仍需核到本人原片和实际裁切。22 个目前能核实作品或发行宣传，尚缺合适的具名单人出处，包括 EVERGLOW《Promise》六位、fromis_9《Glass Shoes》两位、i-dle《I DO》《I Want That》各五位和 WOOAH 出道曲四位。[194 个位置逐项处置](../evidence/20261122-member-release-portraits/remaining-194.csv)

Windows 的选图、IVE 作品入口、NewJeans 详情与原作品图片回归合计 31 项通过。公开与本人两种访问的 126 个卡位比较使用本地渲染和空白测试分数。正式实页的手机和桌面宽度、图片实际解码、原图开关与焦点回返请以本批发布回执为准。[专项用例](../../../apps/idol-site/tests/mv-recognition-editions.test.cjs)
