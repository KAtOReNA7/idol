# 51 团首页在正式站的视觉复核

在 v213 正式站用 Codex 自带浏览器逐团打开首页。窗口宽 1280 像素，正文实测 1265 像素。确认页面进入有效内容后，等待首屏照片解码并留存画面。51 个首页均没有横向溢出，抽取的 67 张可见大图全部解码。检查涵盖 izna、ifeye、UDTT 的原生页面。手机目录结构另有 375 像素的逐页检查。[51 团字体与首图](../evidence/20261122-v213/formal-home-design.json) · [手机和桌面模块顺序](../evidence/20261122-v213/formal-media-order.json)

IVE 的深蓝底、银白字和学院团照在同一屏内形成完整的唱片主视觉，导航使用 2022 年官网团标。NewJeans 的浅蓝导航与团体写真、ADYA 的黑红页头与五人供图、W!TCHX 的深色底与公司具名肖像，各自能从设计原稿和已记录的出处核对。其余团页中，Candy Shop、SPIA、Hearts2Hearts 使用浅底，但首屏仍有清楚的标题层级与团体图像。此次保留这些已验收设计。[四团 Figma 与来源](../evidence/20261121-artist-brand/sources.json) · [其余团标](../evidence/20261121-official-marks/source-marks.json)

真实访问有一个与设计有关的问题。部分大图慢于目录内容出现，首次打开 Cherry Bullet、Kep1er、ifeye 等首页时一度能看到大片空底，原图解码后页面才完整。现有观察没有测得可靠的空白持续时间。后续比较首图开始请求至显示的耗时，可重点区分首屏照片下载、字体加载和首屏布局是否提前预留。手机长目录还存在向上回到分类导航的操作成本。[待讨论的长目录操作](20261122-group-interaction-followup.md)
