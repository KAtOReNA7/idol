# 团照、信息与首页顺序：交付及待办

本轮保持51团现有设计语言，修改首页模块顺序并重选团体索引照片。成员照片按照用户“仅审查”要求逐团记录；没有将不同成员、不同活动时期的照片冒充同一套。

## 本轮已处理

- 51团首页顺序：大图 → 信息 → 成员 → 专辑 → MV → 时间轴 → 其他。原有详情、原图和手帐入口保留。
- 索引照片统一3:2显示框；逐图设置取景，保留来源/时期和原始文件。已重选 16 团：MEOVV、izna、ifeye、GENBLUE、UNIS、VVUP、BEWAVE、ODD YOUTH、Geenius、VCHA、fromis_9、Billlie、Kep1er、NewJeans、XG、KiiiKiii。
- 信息区有117个已核实账号入口、58条人数记录（YouTube 50团，INS/X各4团）；统一万单位，显示真实采集日期，不将平台舍入数写成精确人数。
- 32团有韩国发行累计销量，23团有打歌一位累计；其他项目标待核实。韩国销量不代表全球全渠道总销量。
- 修复GENBLUE、NMIXX和Kep1er窄屏/平板显示问题；恢复Kep1er手机首页MV与桌面时间轴。
- LE SSERAFIM五张成员照片和11张发行封面改从已下载的官网原字节交付，修复官网跨站图片加载不稳定；未更换照片内容。

- 9团销量、4团一位存在来源冲突，未选取任意一方；另有10团缺销量、24团缺一位完整证据。详情见[统计研究](group-information-research-20261025.md)。

- 外部视频缩略图偶有网络加载失败，页面保留作品名、播放入口和重试；不以其他照片替代精确视频。
- 真实生产保存、全视频播放、原生80%/125%缩放及新Figma同步未验。本轮发布保持原owner-private只读范围。
