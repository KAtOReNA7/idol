# Idol Lens 工程优化、Figma 和验证记录

开发分支为 `codex/project-optimization-20261121`，从规划提交 `170d9957` 接续。产品基线为 PR 47 的 `35ff13d3`，已发布版本为 v203。开发范围、原始测量和各阶段验收标准见[全项目路线图](../PROJECT-AUDIT-AND-ROADMAP-20261121.md)。

已落实正式工程的验证入口、合成预览、依赖升级、导入校验与可恢复写入、作品库筛选和导航、首页详情按需加载、媒体授权索引、按主键核对目标及 CRUSH 的精确 P2 封面。公开设计文件中有三个 390 像素宽的编辑状态。[Figma 作品库筛选和导航](https://www.figma.com/design/zeLNExz4TbpWRW3uiahef7?node-id=1305-1095)

第二轮对照 Figma 和真实截图时，发现主站主题的两列规则占用了手机筛选区的第二列，导致「更多筛选」与分类按钮挤在一起。实现改为单列，四个分类各有独立触控区域。浏览回归增加 320 像素宽度以及每个按钮的尺寸、边界和间距断言。

依赖审计剩余的两条根公告分别来自 satori 的 fflate 和 Drizzle 工具链的 esbuild。两个子依赖单独升级，保留原构建框架和迁移工具的版本。最终复扫使用更新后的锁文件，运行验证使用由该锁文件重新安装的实际模块。

逐团复核时，IVE 的目录读取缺少其他团页已有的 JSON 类型和评分数组校验。14 团现在共用一个只读目录请求，保留各页的取消、路由、设计与重试状态。12 个单独页面与 XG、aespa 的共享页面已加进当前回归。图片选择夹具改用按文件与调用方匹配的合成元数据，导航测试为八份公开键表补上内容指纹、来源和字段检查。增加可复跑的 51 团两宽浏览入口，以及三宽搜索、翻页及展开截图。

归档迁移夹具原先按 Unix 文件分隔符识别读取模块，Windows 误走了另一套读取接口。改为比较文件名后，18 项合成迁移测试通过。旧页面内联 URL 断言已迁到共享读取函数及各页的实际调用。仓库另附两个本地预览之间的交错测量脚本，输出完整样本、中位数及公开目录摘要。
