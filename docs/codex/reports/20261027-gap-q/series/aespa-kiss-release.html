7月24日(金)リリース aespa The 1st Japan Mini Album『KISS N TELL』ビジュアル公開！

7月24日(金)にリリースするaespa The 1st Japan Mini Album『KISS N TELL』のアーティスト写真およびジャケット写真を公開しました！

本日解禁されたビジュアルは、アルバムタイトル『KISS N TELL』にふさわしい「幻想的でミステリアスな世界観」を表現しています。
「Limited Edition Ver.」「Poster Ver.」ではレトロフューチャーの雰囲気が漂うサロンにメンバーのカラフルでキッチュな衣装が目を引き、「KISS N TELL Ver.」は巨大なCDの上で、ピンクの色味に統一された衣装に身を包んだメンバーがアイコニックな存在感を放つビジュアルとなっています。これまでに見たことがないメンバーの圧倒的なビジュアルと共に、さらなる進化を遂げたaespaの魅力を堪能できる、芸術性の高いアートワークに仕上がっています！

さらに『KISS NTELL』のCD各形態に封入されているシリアルコードよりご応募いただける、メンバーに会えるスペシャル特典会「サイン会」およびプレゼントも、ぜひあわせてチェックしてください！
