使用实际 WorkDetail、原作品目录以及独立所有者数据渲染三首。访客和所有者的 52 个卡位逐人匹配历史顺序、照片、对应官宣和旧图入口。所有者 26 个评分按钮均紧跟本人图片，访客界面只展示公开资料。在成员作品页分别从图片和文字入口操作 26 张卡，各开本期原图及原作品参照图，104 次点击均打开对应文件。正式站两宽的点图、回焦与评分入口实测由本批发布回执登记。

Windows 图片与私人评分专项 64/64 通过。26 个位置从本人评分入口用隔离数据库保存表现分 0、造型分 8.5，再逐条读回。每首各模拟一次已提交后丢失回执，三次重试后共 26 条保存日志。51 团共 599 支可评 MV 的 4,195 个成员位置均有图片和本人入口，729 个手选成员保存后读回。逐个解码了 52 个实装文件，26 张原图与官宣原字节一致。194 项原台账现已核 112 项，余 64 项已有图集待逐人确认、18 项待找同期依据。[图片回归](../../../apps/idol-site/tests/mv-recognition-editions.test.cjs) · [个人评分回归](../../../apps/idol-site/tests/personal-mv-ratings.test.cjs)
