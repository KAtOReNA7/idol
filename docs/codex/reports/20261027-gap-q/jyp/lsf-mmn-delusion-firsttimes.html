    LE SSERAFIM「Made My Night」最初のビジュアルコンセプト「OUR DELUSION」の写真＆映像公開

    2026.08.31

    • LE SSERAFIM

    この記事の画像を見る

    Facebook X LINE

    LE SSERAFIMが、2ndシングル「Made My Night」の最初のビジュアルコンセプト「OUR DELUSION (Single CD ver.)」バージョンの写真と映像を公開。今回のコンテンツには、記者会見場をコンセプトとして、5人のメンバーの洗練された姿と圧倒的なビジュアルが盛り込まれた。

    ■多数のカメラとマイクに囲まれたLE SSERAFIM

    コンセプトフィルムでは、LE SSERAFIMが多数のカメラとマイクに囲まれながら、メンバー同士で互いに会話を交わしたり、それぞれ考え込んだりする様子が映し出されている。取材陣の熱気の中でも、無関心で堂々とした姿勢が強烈な印象を与える。短く繰り返されるシーンと、素早く切り替わる画面編集を重ねあわせることで、独特な雰囲気を演出すると同時に、記者会見が開かれた理由について興味を抱かせる。

    また、5人のメンバーは、コンセプトフォトでも周囲を意識していないような様子が感じられ、取材陣の視線が集中する状況でもカメラを見つめ、余裕のある笑みを浮かべたり、メモ帳をいじったりしている。一般的な記者会見では見られないような異様な光景が、新鮮に感じられる。

    さらにカラフルな空間と個性的なスタイリングが融合することで、「OUR DELUSION」コンセプトの個性的な魅力が引き立っている。

    LE SSERAFIMは、2ndシングル「Made My Night」の魅力を感じられる様々なコンテンツを用意し、ふたつ目のビジュアルコンセプト「CHEMICAL NIGHT」は、9月2日0時に公開される。その後、9月7日0時にハイライトメドレー、9月8日0時にMVティザー映像など、コンテンツを順次公開し、カムバックへの期待を高めていく。リリースまでの約2週間にわたり繰り広げられるプロモーションを通じて完成する「特別な夜」に世界中から注目が集まっている。
