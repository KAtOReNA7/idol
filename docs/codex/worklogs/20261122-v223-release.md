## 成员链接与滚动位置的修复

此前的渲染检查覆盖 48 个 React 团页，其中 10 团缺少兼顾打开本人及返回原卡的适用入口。WOOAH 使用自己的回焦机制，ifeye、izna、UDTT 分别有独立页面实现。本版 40 次正式成员导航验收针对这 10 团。[逐团浏览范围](20261122-group-journeys.md) · [WOOAH 的回焦实现](../../../apps/idol-site/components/wooah/use-return-focus.ts)

AtHeart、HITGS、VCHA、i-dle、IZ*ONE、fromis_9、EVERGLOW、Rocket Punch、Cherry Bullet 和 Weeekly 共用这套成员链接。点击时先存下原卡、位置和入口，再检查浏览器是否已切换到该成员的准确地址。切换成功才接管点击并滚至资料页顶部。浏览器忽略或拒绝相应历史操作时，照片和资料名上的链接仍可由浏览器直接打开，从独立资料页返回目录也保有可用链接。[成员链接](../../../apps/idol-site/components/artist-roster-link.tsx) · [忽略或拒绝时的导航回归](../../../apps/idol-site/tests/artist-roster-links.test.cjs)

团页共用的滚动处理现在合并连续的位置变更。持续滚动期间每 500 毫秒至多写一次，滚动结束、离开页面或明确点击导航时保存最新位置。已经记录过的相同位置会跳过，旧页面排队的操作也会核对当前地址。[滚动处理](../../../apps/idol-site/components/use-artist-scroll.ts)

用同一隔离浏览器夹具分别载入 v222 与修复后的实现，均按 16 毫秒间隔输入 81 次滚动，终点为 3,149 px。旧实现写入 81 次，新实现写入 4 次，少 77 次（95.1%）。两次最终保存的位置均为 3,149 px。[隔离回放用例](../../../apps/idol-site/tests/artist-history-focus.test.cjs)
