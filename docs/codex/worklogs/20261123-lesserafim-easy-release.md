# LE SSERAFIM《EASY》发行详情

v253 的团体首页和发行目录中，《EASY》都写着「发行日期暂缺」，点击封面会在新标签打开 SOURCE MUSIC。v254 开发版在这两个入口显示 2024 年 2 月 19 日，并在站内打开专辑。看完可分别回到首页或发行目录的原封面。首页仍先列 MV 再列唱片。两个入口各保留原有的 6 张和 11 张卡，其余唱片沿用各自的原链接。发行范围精简为「SOURCE MUSIC 韩国官网收录的 11 项发行」。[两入口与测试读数](../evidence/20261123-v254/lesserafim-easy-release.json)
