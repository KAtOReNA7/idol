# 目录标题和私人手帐页尾

v241 正式团体索引在 1265 px 正文宽度下，有一行 20 px 高的「先认识一个团体，再从一支作品开始。」。页面最下方还显示「我的观看，我的偏好。」。两个位置都没有提供筛选、导航或保存信息。

在项目 Figma 的「团体浏览、评分与原图」页中补绘桌面与手机的标题和页尾。目录标题保留栏目名和数量。桌面的本人导出入口、文件范围和管理入口同排展示，手机纵向排列。访客通过现有导航返回各栏目。[桌面画稿](https://www.figma.com/design/zeLNExz4TbpWRW3uiahef7/?node-id=1539-1639) · [手机画稿](https://www.figma.com/design/zeLNExz4TbpWRW3uiahef7/?node-id=1539-1650) · [团卡与结果区](https://www.figma.com/design/zeLNExz4TbpWRW3uiahef7/?node-id=1447-1301)

开发提交 `6966b2d7` 将团体、成员及作品目录的标题直接接到操作区，移除四组隐藏英文小标题和页尾口号。私人记录搜索仍说明可搜索的字段。访客省去只有站名的页尾，本人仍可看到导出范围，管理入口继续沿用原鉴权。Windows 类型检查通过。团体目录、公开团卡、首页简介与产品文案共 67 项定向测试通过。正式站结果随对应发布记入版本回执。
