# 逐团使用与访问优化

IVE 首页在 v210 正式站会连续请求三份相同目录，每份解码后为 199,409 字节。ADYA 两份，各 16,231 字节。Cherry Bullet 已经只读一份，共 46,966 字节。首页信息和时间轴现直接使用当前团页持有的目录。请求错误和重新读取仍由团页处理。

在同一内置浏览器会话依次对照 v210、v211 的正式首页，目录请求和解码后的响应体积如下。三个团的单份响应大小分别与各自前一版本相同。此项未采集加载耗时。

|---|---:|---:|---:|
| IVE | 3 → 1 | 598,227 → 199,409 | 398,818 字节（66.7%） |
| ADYA | 2 → 1 | 32,462 → 16,231 | 16,231 字节（50%） |
| Cherry Bullet | 1 → 1 | 46,966 → 46,966 | 0 字节 |

作品库的内置浏览器用例按真实团体筛选作品，搜索一个没有结果的词、清空，再逐首打开、切换有来源的舞台并从详情返回。团体栏目、独立发行和影像、时间轴定位，以及通用和团内成员档案另测。只读预览使用项目的正式构建，公开目录从同一仓库快照投影，并清空用户评分与备注。素材投递和第三方视频解码在正式站单独核对。

在这个预览中，51 团都能从作品详情回到作品列表。共打开 605 支 MV、切换 527 个舞台、检查 9 个占位页的返回入口。有作品可搜的 50 团均通过搜索清空。初跑快速连续点击时有七团超时或未返回目标页，按实际阅读节奏重试七团均通过。48 个 React 团内的 320 个成员档案显示了所请求的成员 ID。

合并三轮本地读数，2,929 个不同的团体、页面与操作组合完成核验。UDTT 的 7 个栏目入口、3 张发行、2 个媒体详情、3 个事件和 5 份团内成员档案分别在 v211 正式站打开，20 处都读到了对应的标题或姓名。按团体、类型、记录 ID 与路径去重后，两端合计覆盖计划内的 2,949/2,949 个组合。作品详情与舞台切换测的是页面行为，播放清晰度有单独的实播记录。[逐团与逐类结果](../evidence/20261122-v211/browser-journeys.json)
