开发提交 `4d41b5aa` 的默认五张图共 148,480 B，原文件共 2,136,354 B，按同一组卡片的文件字节数减少 93.05%。五张预览均为 480 × 640，五张原图均为 736 × 1104。三张新原图只在打开时加载。DOEUN、JIEUN 继续引用原件，两人各自只有一个大图入口。
