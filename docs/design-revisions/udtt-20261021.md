# UDTT 重设计任务与保护基准

日期：2026-10-21。范围仅 UDTT；本文件是最新用户任务记录，不修改通用设计准则，不授权新增凭证、权限、发布或资料写入。

## 一、用户明确决定

上下文：主会话询问用户最认可的部分是否为旧版竖向成员大图。用户明确确认，并连续要求：
1. “对”
2. “保留这个，其他我建议你全部重新设计”
3. “参考完后让figma设计”

因此，保护对象是旧版竖幅成员摄影的冲击力，不是 v184 的小卡片方案；其余区域包括首屏、作品区域，以及成员目录、成员详情、作品目录、作品详情、时间轴等全内页，均进入重新设计范围。不能将此缩减成只补空白、调字号或修一个模块。保留摄影方向不等于机械保留旧实现缺陷。

通用要求继续遵循 [设计要求与验收基准](../design-requirements.md)；历史固定需求参考提交 e9dfacf3f38b20ec204d983bd8fc3edf696ada0c。本次只追加专门任务，不覆盖其他团或并发交接。

## 二、v184 的状态与已确认问题

- v184 被用户否决的是设计结果。技术测试通过、图片正确、链接可用，均不等于视觉验收通过，不得再称为已获用户认可的成品。
- v183 基线为 3ca624cfb15055d7e4f2fa088fe32edbeb75bbe8；v184 为 8247e8bda8800076e57f03988217eee236fa173a。
- 精确源码回溯表明：没有删除首页模块或团体大图，首页主体结构和首屏样式未变。不能把此次问题错误归因为“首屏被删除”。
- 成员照片统一增加 height:auto 后，由旧版高长视觉变成较小照片卡片，摄影冲击力和长页节奏明显减弱。原来异常高度不应直接恢复，须重新设计正确比例的竖幅视觉。
- 发行区由左右两列改成一列、取消标题宽度限制，是实质版式改动，不能只称“修复空白”。
- 陆雨婷卡片中新增的技术说明占用空间，使姓名位置低于其他成员。技术说明应退到来源折叠区；卡面仅保留读者有用的历史年代等简短说明，姓名层级与基线需统一。
- 设计审阅入口 /design-review/sol15/udtt 与另一套 /artists/udtt 原本就是不同实现。本轮不把入口混淆当作已证实原因；审阅必须记录确切入口和版本，避免比较错对象。

## 三、必须保护与保留

### 视觉保护
- 旧版“认识成员”区域的竖向大幅摄影，是用户明确认可的视觉基准。原复审证据中的截图 02 可用于理解摄影尺度、人物识别与纵向节奏；本文件不上传该截图，不暴露内部保存路径。
- 保留大幅竖向摄影的存在感；人物不拉伸，不机械还原异常像素高度，不用小方卡替代大图。
- 如需裁切，必须逐图选择与审阅构图，保留关键人物识别信息；不得把统一拉伸或无依据裁切称为设计。
- 正确陆雨婷照片必须保留。它是已核验的历史照片，640×800；年代/时期必须诚实，不冒充当前同批宣传照。
- 其他成员照片不能因布局调整被替换、移除或降成无辨识度缩略图。

### 功能与资料保护
- 保留正确图片读取与校验、照片查看器、成员与已核实作品关系、返回上下文、键盘焦点、错误/等待/取消与回收等已验证修复。
- 不将历史时期不同的成员自动加入同一支 MV；保留已有精确事实边界。
- 不改用户评分、备注、观看状态、记录、权限、鉴权、存储或旧图恢复链。
- 设计否决不自动授权整站回滚或删除技术修复；新设计须与正确资料及已有功能整合。

## 四、严格执行顺序

1. 真实参考观察：实际打开并观察 UDTT 可核实官网、Spotify 艺人/正式发行页面及正式作品视觉。记录已访问来源、具体观察和可借鉴点。访问受阻必须记录；不得以搜索摘要冒充看过页面，不得编造官方来源。
2. Figma 原生设计：参考完成后，在 Figma 中完成可审阅的原生页面设计。保护竖幅成员摄影，重新设计其余首屏与全部内页，明确桌面/手机构图、字体、色彩、图片尺度、信息层次、导航与状态。不能先做通用代码模板再补一个名义上的 Figma 文件。
3. 截图审阅：审阅 Figma 实际画面与旧版受保护摄影基准，覆盖首页及各内页、关键响应式宽度。明确哪些设计通过、哪些待改，不将“已生成”写作“已验收”。需要用户确认时交清晰设计画面，不交技术压缩包。
4. 代码实现：设计审阅认可后再按设计实现，逐页核对，保留上述技术修复。通过真实浏览器检查后，才按当前有效授权进入发布；最终仍由用户人工确认成品网页。

## 五、不可替代与交接要求

- 禁止以灰框、占位图、线框拼接、通用目录卡片、测试数量或构建成功替代设计完成。
- 禁止只解决工程问题便宣布“符合 Spotify/官网风格”；必须有真实参考、Figma 原生画面和截图审阅依据。
- 分工指令必须先读本文件，明确“竖幅成员摄影保护、其余全部重设计”，并分别列设计目标、事实边界、功能保护与验收入口。
- 首屏未在 v184 被删除，不代表首屏可免于此次重新设计。最新用户要求已明确扩大到除受保护摄影方向之外的其余区域。
- 不擅自扩大到其他团，不修改通用需求文件以为局部妥协背书。
- 当前文档提交仅记录任务，不表示参考研究、Figma 设计、代码实现或新一轮发布已完成。
