### 成员图实测

在 v215 上按默认成员卡逐个核对了 42 个不同的正式文件，对应 63 个位置。v216 的 63 张 WebP 预览合计 2,211,244 字节，63 张按需打开的完整原图合计 52,524,285 字节。126 个正式请求均返回 200，每张图的文件字节、尺寸和实际解码均已核对。[每个成员的正式图片](../evidence/20261122-v216/formal-mv-images.json)

如果八支作品各打开一次，并按每张成员卡计其默认展示文件，24,078,390 字节降至 2,211,244 字节，减少 90.82%。旧版多个作品曾共用相同 URL，按每个文件只算一次，23,251,746 字节降至 2,211,244 字节，减少 90.49%。ITZY《In the morning》的默认展示总量单独增加 66 字节。[每支作品与两种大小口径](../evidence/20261122-v216/formal-image-comparison.json)

正式站按手机正文宽 375 px 和桌面正文宽 1,265 px 各测一遍。两种宽度下，63 张新卡均逐张打开了本人的发行原图，按 Escape 后焦点回到原按钮。每张卡的评分入口都在本人照片正下方，可展开表现分、造型分与保存入口。另有 57 张卡还保留不同的旧作品照，两种宽度下均已打开、解码并回焦。正式私人写入为零。[手机逐卡操作](../evidence/20261122-v216/formal-mv-mobile.json) · [桌面逐卡操作](../evidence/20261122-v216/formal-mv-desktop.json)

### 首图载入

四张首页默认展示图在 v215 正式站合计 11,238,516 字节，v216 合计 1,216,442 字节，减少 89.18%。新版的四张展示图与四张原件均从正式站返回 200，解码后与对应文件一致。[八个正式图片请求](../evidence/20261122-v216/formal-home-images.json)

Codex 内置浏览器在实测正文宽 1,265 px 的正式首页每团每版各访问两次，记录到团照解码的时间。三个团此次都更早看到主图，幅度因团而异。基线取自 v214，期间 v215 的变动是直达 MV 读取。

| 团体 | 图片显示宽度 | v214 中位时间 | v216 中位时间 | 提前 |
|---|---:|---:|---:|---:|
| Cherry Bullet | 1,002 px | 2,254 ms | 998.5 ms | 1,255.5 ms |
| Rocket Punch | 715 px | 3,626 ms | 2,331 ms | 1,295 ms |
| Weeekly | 1,046 px | 2,403.5 ms | 1,669.5 ms | 734 ms |

表中计时只覆盖团照，四张文件的大小统计另含 Weeekly 横幅。[逐轮正式读数](../evidence/20261122-v216/formal-home-timing.json)

逐团在照片刚出现时点击原图，三个首页第一次都没有响应。再次点击均成功打开原始 JPEG，关闭后焦点回到原处。首次点击的问题已复现，后续须在同一时机验证一次点击就能打开。[三团按钮实测](../evidence/20261122-v216/formal-home-clicks.json)
