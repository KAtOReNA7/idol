# 无既有成员关系作品：本轮处理结果

本目录只含公开作品署名、认人参考与研究证据，不创建或修改私人评分关系。131 个作品逐项保留稳定 ID 与精确视频 ID；现有 2840 条有效关系的图片不重复补图。

- 公开署名从 16 支增加至 **37 支**，新增 21 支／118 人次，合计 **239 人次**。这里只表示相应来源范围：具名参演报道、发行阵容、录音阵容或部分官方宣传署名，不能统称完整 MV 参演表。
- 37 支作品提供 239 个公开认人参考槽。**102 个独立原件**中，92 个沿用既有审过原件，10 个为新图：GIRLSET 官方成员写真 4 张、KATSEYE Beautiful Chaos / Beautiful Ver. 具名同系列 6 张。10 个新原件共 7,134,512 字节，完整原图保留；均已按实际 3:4 裁切视觉检查。
- SUHYEON《ZAP》另有独立提质候选 1 张，700×1050、76,628 字节：Dispatch 同稿的 Nate 转载第三张近景。姓名和拍摄系列可追溯，发型/黑色服装不同于旧全身照，不冒称完全同套服装。接入与发布由主任务记录，旧图和原生关系不改。
- 131 个精确 YouTube 页面取得 128 个匹配 videoDetails；3 个当前未返回播放器资料。互斥结果为：**公开署名 37、保留已证无成员真人 5、尚无可采用人物署名 89**（86 已取得说明，3 读取失败）。取得标题/描述不代表出镜核验完成；本轮没有完整播放全131，也未穷尽全网研究。

## 已采用与拒绝的关键证据

GIRLSET《CHAT》《Little Miss》发行正文明确具名 MV 表演者；《Tweak》只作当次发行阵容。MADEIN S《BLUE》只列具名四人项目，不带入母团所有成员。BADVILLAIN《HURRICANE》用艺人方赞助发行资料，保持用户确认的正式 MV `00tUzCOPI6g`；不能混淆 Performance Video。

KATSEYE 2025 三作品的六人发行阵容与 2026《WILD》的五人录音阵容分开。Apple Music 专辑说明明确 Manon 未参加该 EP 录音；通用唱片公司成员介绍仍列六人，不能据通用页脚扩大这次录音名单。XG 四作品仅据《The Core》首发报道展示发行阵容。BABYMONSTER《MOON》只列官方目标曲视觉公告已具名四人，标记为部分宣传名单。

VVUP《Super Model》采用 Genie 官方 MV 拍摄照片逐人署名；《House Party》仅采用 Cosmopolitan 的当次作品采访阵容。QWER《SHOW DOWN》采用 iMBC 的目标曲预告／发行报道，预告出演与完整正式 MV 核验分开。

IZ*ONE《D-D-DANCE》用 Soompi 逐日具名概念照宣传记录覆盖12人；该报道说明2021原MV在UNIVERSE首发，本目录对应2023 GENIE MUSIC重新上传，因此只标宣传署名，不冒称核验该上传全部出镜。认人图复用此前已确认的官网 One-reeler 同系列12张，已按实际3:4重新检查；黑蓝圆形摄影背景属于原片，没有额外加边。AtHeart《Butterfly Doors》用 Korea Times 目标发行采访和 Titan 具名图注列6人，Aurora健康休息不列入；复用 Plot Twist / Melon 紫色服装同系列6图，只标认人后备，不标本曲妆造。

YouTube 中通用成员 hashtags 不作为参演证明；tripleS《Just Do It》描述列20名标签但NXT项目只有4人，足以说明此捷径会造成错误。GENBLUE《Night Market Queen》描述含演员角色名单，不能将外部演员写成既有团员。未读取到正文的搜索片段不作为主证据。

## 剩余89的分类与解决办法

分类按精确视频官方标题与现有描述分流，互斥合计89；分类本身不证明成员有无出镜。制作人员字样、cast字样、hashtags另外记录为可重叠标记，不充当完成数量。

|类别|数量|解决路线|
|---|---:|---|
|普通 MV／待人物署名|29|按目标发行找具名采访、逐人宣传照、制作方 cast 或官方幕后；部分来源只展示有限署名。|
|表演／现场|16|核对这一精确版本的字幕、节目名单或具名幕后，不移植原MV全员。|
|短片／特别视频／宣传片|11|找独立片尾、制作页与人物说明，分清品牌片、track film、剧情演员和团员。|
|混音版本|11|核制作方式与全片；不同 remix 和 Other World 版分别处理，不自动判无人。|
|语言／声学／地区版本|7|核该版本发行资料及镜头是否复用；同曲不同版不能直接复制名单。|
|影视／动画 OST|5|分离演唱署名、剧情演员与真实团员；需要精确视频完整检查。|
|歌词版|3|歌词视频也可能使用真人镜头；先看全片和制作资料，再判断是否仅MV评分。|
|联名／合作项目|3|查合作方具名制作和录音资料，外部艺人不映射为团员。|
|精确页资料受阻|3|BADVILLAIN《+82》、ILLIT《Almond Chocolate》Special Film、NMIXX《FEIFEI》；保留ID，查官方替代入口或存档，不换近似视频。|
|角色版|1|IVE《BANG BANG》MINIVE版需核全片与真人彩蛋；角色标题不足以关闭成员评分。|

没有发现标题明确写 Visualizer 的开放作品。完整逐项路线、来源页哈希、采用条件和当前阻碍在 `remaining-work-format-routes.json`；131总账保留旧分类与新增当前分类，历史不会被覆盖丢失。

另保留5项“可能无成员真人”的**研究候选**：aespa《Regret of the Times》《Supernova (Grimes Remix)》《Armageddon (Flava D Remix)》《Rich Man (Yellow Claw Remix)》、IVE《BANG BANG (MINIVE VER.)》。现有独立资料提示无成员、纯数字画面、AI制作或角色版，但尚未满足“精确视频完整核查＋足够独立可靠的明确证据”。本轮新增无真人规则0，原5条规则不变。AI工具、remix、OST或歌词标签均不能替代完整核查。

当前真正需要后续证据的是89条人物/版本结论，不是原871缺图再开工。可提供帮助的具体信息为：精确视频的具名幕后/制作字幕、可靠采访或有姓名的同次宣传档案；无需靠用户凭脸猜人。未解决项仍保留为开放，不能将分类完成或搜索失败写成内容全部补齐。
