## 记录格式

每次交付至少记录：团体、实际 Git commit 或 source 标识及其类型、资产清单版本、数据模式、预览环境和 URL、检查时间、检查者、测试项、实际结果、截图或日志相对路径、尚未完成项。

使用明确状态：`通过`、`失败`、`未测`、`受阻`、`不适用`。不适用必须说明原因。用户人工状态另记为 `待反馈`、`需修改` 或 `已认可`，不可由开发者代填已认可。

## 设计验收

- [ ] 实际查看官网、Spotify 等正式视觉参考，能说明本团的设计选择。
- [ ] 首页和主要内页构图、字体、材质、颜色、交互保持独立且连贯，不是通用底板换色。
- [ ] 合格既有设计被保留；Billlie、UDTT 4+1、YOUNG POSSE、i-dle 未因统一模板被推翻。
- [ ] GENBLUE BlueCut 与 WOOAH 黑色时尚实图保持各自表达。
- [ ] 真实图片进入 Figma；页面/节点映射、实际取稿与关键截图可查。
- [ ] 首页可直接看到适用名册全员照片与中文名；成员不全是小头像，不藏在轮播或弹窗后。
- [ ] 看完整长页，不仅首屏；没有标题孤列、图片规格冲突和失衡的大空白。
- [ ] 不把开发、核验、审计标签或编造的品牌标语作为主要前台内容。

## 功能验收

- [ ] 首页、成员目录、成员详情、作品库、MV/舞台详情、评分或既有手帐、时间轴与返回入口都实际可用。
- [ ] 完整执行“首页 → 成员 → 精确关联作品 → 评分或既有手帐 → 返回”。
- [ ] 搜索和筛选有效，返回正确恢复筛选、合理滚动位置与焦点。
- [ ] 图片完整加载；查看器可打开/关闭，Escape、关闭按钮、遮罩与焦点恢复正确。
- [ ] 视频链接对应精确版本，外链失败不伪装为播放成功。
- [ ] 评分 0、null、0.1 步长、清空均正确；MV、舞台、成员与造型评分不串对象。
- [ ] owner-only 写入由服务端保护；公开可读不等于匿名可写。
- [ ] 未保存提醒、成功/失败/冲突反馈、重试和不确定结果处理完整。
- [ ] synthetic、只读候选和真实持久化模式清楚区分；模拟保存不显示成真实线上已保存。
- [ ] 浏览器没有本轮引入的运行错误，样式未污染其他已认可团体。

真实保存测试应在授权的环境及记录上进行，先检查可恢复性，不用真实评分进行未经授权的试写。未做真实写入时，应保留该项未测，不扩大合成结果。
