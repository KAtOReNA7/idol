# 成员作品卡和账号显示的旧回归修复

九个团体的成员页测试仍依赖旧缺图文案、整页图片数或未换算的粉丝数字。Hearts2Hearts 另有一项测试只查源文件中是否存在某段 JSX。现有界面为已知照片提供原图入口，并按作品和成员关联展示个人评分。用户已确认账号人数按整数万展示，同时保留原始精度和日期。[人数显示决定](../mv-style-completion-report-20261026.md) · [成员页模块顺序](../member-layout-implementation-20261030.md)

现行测试在 Hearts2Hearts、ITZY、KATSEYE、KiiiKiii、KISS OF LIFE、LE SSERAFIM、NMIXX、SAY MY NAME 和 STAYC 的实际成员页组件中逐行核对。页面上有本人档案照，作品缺图时仍可读到表现 0、造型 8 和作品入口。加入另一名成员的满分及照片后，当前成员的行数和综合分 4.0 均正确。绑定本人的照片后，行内原图按钮使用本人评分记录的附件索引。故意改成另一条记录的照片后，该图消失。清空造型分时，表现仍计 1 支、均分 0.0，造型计 0 支，综合分显示待评。九团的作品入口均保留原成员返回路径。[成员作品卡验证](../../../apps/idol-site/tests/helpers/member-work-card-contract.cjs)

Hearts2Hearts 单独核实同页可看到官方成员照，缺少对应作品照时，作品评分行不会冒出可放大的图。XG 和 aespa 的账号测试读取具体成员主页链接，原值 10.2 万显示为 10 万，记录日期和原始值均保留。这批只修改测试，使用合成数据。
