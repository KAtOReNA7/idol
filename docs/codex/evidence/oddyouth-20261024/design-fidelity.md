# ODD YOUTH：蓝白相册方向与对照

本轮网页参考的是 TOP MEDIA 的 ODD YOUTH 首页及具名 PROFILE 页，实际查看了蓝皮卡户外合照、五张自然光方形肖像和页面结构。发行资料与正式封面另取 Bugs 及 TOP MEDIA 目录；视频缩略图按精确 YouTube ID，不按同名歌曲替代。官网为 https://www.itopgroup.com/bbs/page.php?hid=ODDYOUTH 。

采用蓝色开场面板、完整团照、白底五人等大相册、年份窄栏发行行和单根蓝色时间轴。英文字体为 Syne，中文保持无衬线可读性。主要内页沿用这一套构图和色彩；未复用 Candy Shop 的粉紫视觉底板。

## Figma

[设计页](https://www.figma.com/design/zeLNExz4TbpWRW3uiahef7?node-id=1022-1095) 包含八类页面 × 1440/390/320，共24个原生画板。真实图片作为单独填充，文字、自动布局、六种颜色变量和两种动作组件均可编辑，未使用整页截图当交付。

已取得主要内页及手机画板的 get_design_context 与截图。修正首屏合照比例、长中文标题、窄屏按钮、成员作品行、视频操作栏和连续时间轴；清除临时采集节点。结构检查24画板无右侧越界。截图存于本机外部可视化目录，映射与工具证据记录在同目录 JSON 中。

Figma 与网页不是逐像素相同：网页响应式尺寸、中文字体回退、首页出血与按钮间距以实际实现为准；共享手帐保留既有 stage 壳和完整控件，Figma 覆盖只读作品与成员记录的主要布局，未逐项复刻所有共享壳控件。此项仍需后续细节同步，不记为完整 Figma 保真验收通过。

## 验收范围

- 网页：八类页面五种实际视口；成员搜索、完整原图/焦点、发行/视频身份、手帐往返与图片失败重试通过。
- 资料：五成员、五发行12曲目、11视频、五事件；15个既有成员作品关系只属于原三MV。新视频没有虚构native评分或成员关系。
- 未核：Best Friendz Live Clip 的实际演唱语种；官网未标清字段的生日；实际活动/合同状态不由资料页外推。
- 未验：原生80%/125%缩放、真实认证写入、视频播放、生产API故障恢复。线上只完成v24首页打开，点击工具超时，不能称线上全链通过。
